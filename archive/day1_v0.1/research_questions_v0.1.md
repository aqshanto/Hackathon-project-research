# Research Questions

## RQ1: Model Performance

**Which machine learning model provides the best predictive performance for classifying Mobile Financial Services (MFS) transactions into Heavy and Light processing workloads?**

## RQ2: Impact on System Performance

**How does the choice of machine learning model affect the following system performance metrics?**

- End-to-end routing latency
- Transaction throughput
- Simulated infrastructure cost

## RQ3: Routing Strategy Comparison

**How does workload-aware routing perform compared with the following routing strategies during normal traffic and festival traffic surges?**

- Round Robin
- Weighted Round Robin
- Least-Loaded Routing
- Rule-Based Routing

## RQ4: System Robustness

**How robust is the proposed workload-aware routing system under the following adverse conditions?**

- Node degradation
- Complete node failure
