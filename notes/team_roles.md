# Research Team Roles - Version 0.2

## Member 1 - Literature and Dataset Lead

- search and organise related work;
- maintain the literature matrix;
- verify the selected PaySim source, version, provenance, and license;
- inspect dataset schema and distributions;
- document valid pre-routing features and leakage risks;
- draft the Related Work and Data sections.

## Member 2 - Model and Evaluation Lead

- build the shared regression benchmark pipeline;
- implement candidate regression models;
- perform fair hyperparameter tuning;
- calculate MAE, RMSE, R-squared, inference latency, and model size;
- perform error analysis and statistical comparison;
- prepare model-comparison tables and figures.

## Member 3 - System Experiment and Reproducibility Lead

- implement the FinCluster reference processing pipeline;
- create controlled Docker node profiles;
- collect repeated service-time and resource measurements;
- integrate the winner model into the routing engine;
- run traditional-routing and ML-routing experiments;
- maintain experiment configuration, seeds, logs, and Git history.

## Shared Responsibilities

- finalise research questions with the mentor;
- validate the pipeline and measurement protocol;
- interpret results without overclaiming;
- write and revise the paper;
- prepare presentations and reviewer responses;
- verify every reported result and citation.

Roles are provisional and may be adjusted after the mentor meeting.
